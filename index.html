Give each task to the astronaut rested enough to do it.

AFAQ reads each astronaut's sleep, heart rate and stress from a wearable band, scores their fatigue for every work block, and solves an integer program for the schedule with the lowest fatigue exposure. Every mission-critical task still gets done.

How it works

Band → Excel → Optimizer → Band

Sense

Band vitals

Sleep last night, wake-up time, resting heart rate vs. normal, stress score 0–100.

Score

Excel fatigue model

A fatigue score per astronaut per work block. Cost of each assignment = difficulty × fatigue.

Solve

LINGO integer program

Minimizes total fatigue + peak fatigue + workload gap, subject to skills, time windows, crew size and rest.

Act

Back to the band

Each astronaut sees their next task, who they work with, and when they rest.

The problem

Crew schedules are planned around fixed timelines and rarely adjust to how tired each astronaut actually is on the day. As missions to the Moon and Mars get longer and more autonomous, crews will need to re-plan on board. Existing tools mostly predict fatigue or plan sleep; few use fatigue to decide who does each task, and when.

How can we schedule astronaut tasks to reduce fatigue exposure and balance workload while meeting every mission requirement?

Objectives
01

Build the optimization model. An integer program that assigns tasks to astronauts across time blocks, subject to deadlines, required skills, minimum sleep and a daily work limit. Solved in LINGO, data in Excel.

02

Reduce fatigue exposure. Minimize total and peak fatigue per astronaut, at least 13% below a manual first-available baseline whenever the crew has spare capacity.

03

Balance workload, keep productivity. Shrink the gap between the most and least loaded astronaut while completing 100% of mission-critical tasks. Checked with a sensitivity analysis on crew size and workday length.

Sensitivity

A longer workday raised AFAQ's peak-fatigue gain in S4 (shifted sleep) from 14.3% to 25.4%: more blocks give the solver more room to move hard tasks away from tired astronauts. Cutting the crew to three (S5) removes that room entirely.

Trade-off

In some scenarios AFAQ accepts slightly more total fatigue to protect the most tired astronaut and balance workload. The objective weighs all three terms; change the weights in the builder to see the trade-off move.

05 · Model & code

The math behind the schedule

One integer program, written three ways: the formulation, the Excel workbook that builds its data, and the LINGO code that solves it. The browser solver on this page runs exactly the same model.

Formulation

xa,j,b ∈ {0,1}  = 1 if astronaut a does task j in block b
min Z = Σa Fa + P + (Lmax − Lmin)
Fa = Σj,b dj·fa,b·xa,j,b    La = Σj,b dj·xa,j,b
Coverage
Σa,b xa,j,b = crewj for every task (docking needs 2)
One at a time
Σj xa,j,b ≤ 1 for every astronaut and block
Daily limit
Σj,b xa,j,b ≤ max tasks per astronaut
Peak
Fa ≤ P for every astronaut
Balance
Lmin ≤ La ≤ Lmax
Eligibility
x exists only if a is qualified, awake, and b is in task j's time window
fa,b = 1 + 0.1·awake + 0.15·sleep lost + 0.02·ΔHR + 0.004·stress

06 · Versus prior work
Circadian Stability (NASA Space Apps 2020) and AFAQ

      
Circadian Stability was a Global Nominee for the Sleep Shift Scheduling Tool challenge. It plans one person's sleep, meals and exercise with weighted interval scheduling in Python. AFAQ takes the sleep period as given and decides who does each task, and when. The two tools complement each other.

8 h
Body-clock shift
For a normal sleeper (23:00–07:00) with docking at 02:00–04:00, their tool moved sleep to 15:00–23:00. That shift is exactly what the tool aims to prevent.

      
−2%
Below its own optimum
Under their own weights the best schedule scores 21,591 and keeps sleep at 23:00. Their algorithm returned 21,159. Loop-index and tag-limit bugs in the dynamic program cause the miss.

    

    

      
How we checked

      
We ran their code from the public repository, then enumerated every option under their own scoring to find the true best. For AFAQ we enumerated all 152 feasible Scenario 2 schedules: LINGO's answer (Z = 62.14) is the minimum.
